SAVE TO GITHUB

GitHub sync

Your progress is committed to a file in your own repo, so it's saved for real and versioned. The token stays only in this browser.

Setup, once (2 min)

1. Create an empty repo (e.g. cae-progress). It can be private.
2. GitHub → Settings → Developer settings → Fine-grained tokens → generate one with Repository access: only that repo and Contents: Read and write.
3. Paste it above and press Connect. The app creates the JSON file on first save and commits every change after.
4. To open the app anywhere: put this index.html in a repo and turn on GitHub Pages — or just open the file locally. Both sync to GitHub.
